        รูปแบบแผนที่

        แผนที่ใช้ข้อมูลฟรีจาก OpenStreetMap + OSRM ไม่ต้องใช้ API Key และกดส่งต่อไป Google Maps ได้ทันที

        สัดส่วนหน้าจอแสดงผล

        ธีมหน้าตั้งค่า

        วิธีเปิด Mirror ขึ้นจอรถ / ติดตั้งเป็นแอป (PWA)
        1. เปิดลิงก์เว็บ (HTTPS บน GitHub Pages) บนมือถือ แล้วเลือก เพิ่มลงหน้าจอโฮม (Add to Home Screen)
        2. แตะปุ่มกลมตรงกลาง ขับขี่ เพื่อเข้าสู่โหมดเต็มจอแนวนอน + กันหน้าจอดับ (Wake Lock)
        3. หากใช้กับจอรถ (เช่น Zontes 368K MotoPlay / EasyConnect) ให้เลือกสัดส่วน 5:3 แล้วแชร์หน้าจอมือถือตามปกติ
