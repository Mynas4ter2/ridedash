# RideDash — Mobile Riding Assistant (PWA)

หน้าจอผู้ช่วยขับขี่สไตล์ Android Auto ส่วนตัวสำหรับมือถือ (และเปิดเต็มจอแนวนอนเพื่อ Mirror ขึ้นจอรถได้) ออกแบบเน้นมินิมอล สบายตา เป็นมิตรกับผู้ใช้ใหม่ ทำงานเป็น Static Web App / PWA เก็บข้อมูลในเครื่อง 100% ไม่ต้องใช้ Backend หรือ API Key

## ฟีเจอร์หลักที่ใช้งานได้จริง
- **โหมดขับขี่เต็มจอแบบปรับแนวอัตโนมัติ (Adaptive Ride HUD)**: รองรับทั้ง **แนวตั้ง** (ใช้งานมือเดียวบนตัวยึดมือถือ) และ **แนวนอน** (ติดแฮนด์/หน้ารถ หรือ Mirror ขึ้นจอรถ) พร้อมปุ่มสลับ **โหมดกลางวัน/กลางคืน** และ **Screen Wake Lock** กันหน้าจอดับ
- **แผนที่และนำทางเสียงภาษาไทยจริง (Leaflet + OpenStreetMap + OSRM + Web Speech API)**:
  - แสดงตำแหน่ง GPS เรียลไทม์, ค้นหาสถานที่และจุดใกล้ฉัน (Nominatim), คำนวณเส้นทางพร้อมลูกศรบอกทิศเลี้ยวและเวลาถึง (ETA) แบบนับถอยหลังจริง
  - **เสียงนำทางภาษาไทย (`th-TH`)** แจ้งเตือนล่วงหน้าก่อนถึงทางเลี้ยว และ **คำนวณเส้นทางใหม่อัตโนมัติ (Auto Re-routing)** เมื่อออกนอกเส้นทาง
  - ปุ่มส่งพิกัดเปิดนำทางต่อใน **Google Maps** ได้ทันที
- **ลิ้นชักทางลัดสถานที่**: บันทึก **🏠 กลับบ้าน** และ **💼 ที่ทำงาน** พร้อมปุ่มค้นหาสถานที่ใกล้ฉัน (`ปั๊มน้ำมัน`, `คาเฟ่`, `7-Eleven`, `โรงพยาบาล`) ในลิ้นชักพับเก็บได้ใต้ช่องค้นหา
- **GPS จริง + โหมดจำลองขี่ตามเส้นทางจริง**: อ่านความเร็ว (km/h), เข็มทิศ และระยะทางจริงจาก GPS พร้อมโหมด **"🧪 จำลองขี่"** ที่วิ่งตามเส้นทางจริงบนแผนที่เพื่อทดสอบเสียงนำทางในบ้านได้
- **โหมดปลอดภัย (Safe Mode)**: เมื่อความเร็วถึงเกณฑ์ที่ตั้งไว้ ระบบจะซ่อนแผงเพลงและปุ่มไม่จำเป็นเพื่อให้เห็นแผนที่ คำสั่งเลี้ยว และความเร็วชัดเจนที่สุด
- **เครื่องเล่นเพลงในตัว + Media Session API**: เลือกไฟล์เพลงจากเครื่อง (`.mp3`, `.m4a`, `.wav`), ฟังวิทยุออนไลน์, รองรับปุ่ม Play/Pause/Next/Prev บนหูฟัง Bluetooth หมวกกันน็อก และปุ่มทางลัดเปิด Spotify / YouTube Music
- **โทรด่วน (Speed Dial)**: ปุ่มใหญ่กดง่าย โทรออกได้ทันทีผ่าน `tel:` พร้อมเพิ่ม/ลบเบอร์เองได้
- **สภาพอากาศจริง (Open-Meteo)**: แสดงอุณหภูมิและความชื้นตามพิกัด GPS ปัจจุบันฟรี
- **บันทึกทริปอัตโนมัติและคำนวณค่าน้ำมัน**: เริ่มบันทึกทริปอัตโนมัติเมื่อเริ่มนำทาง, เก็บประวัติทริปและประวัติเติมน้ำมันถาวรในเครื่อง (`localStorage`), ประมาณการค่าน้ำมันเดินทาง, คัดลอก CSV, และสำรอง/กู้คืนข้อมูล JSON
- **ข้อตกลงและความเป็นส่วนตัว (Terms & Privacy)**: แสดงข้อตกลงความปลอดภัยและนโยบายความเป็นส่วนตัวตอนเข้าใช้งานครั้งแรก และเปิดอ่านซ้ำได้ในหน้าตั้งค่า

## วิธี Deploy ขึ้น GitHub Pages (HTTPS ฟรี)

1. Push โค้ดขึ้น GitHub Repository ของคุณ (Branch `main`)
2. ไปที่หน้า Repository บน GitHub → **Settings** → **Pages**
3. ตรง **Build and deployment** เลือก Source เป็น **Deploy from a branch** → เลือก Branch `main` โฟลเดอร์ `/ (root)` → กด **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้ของคุณ>.github.io/ridedash/` (HTTPS พร้อมใช้ GPS จริง)

## วิธีติดตั้งเป็นแอปบนมือถือ (PWA)
- **Android (Chrome)**: เปิดลิงก์ GitHub Pages → กดปุ่มติดตั้งในหน้าตั้งค่า หรือแตะเมนู `⋮` → **เพิ่มลงหน้าจอหลัก (Add to Home screen)**
- **iOS (Safari)**: เปิดลิงก์ → แตะปุ่ม **Share** → เลือก **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**

## วิธีรันทดสอบในเครื่อง (Local)
```bash
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`
